# SVG 转 TTF

将 Illustrator 输出的 SVG 向量图批量转换为可安装的 TTF 字体文件。

## 功能说明

设计师用 Illustrator 描摹手写字或图形字后，需要把成果变成实际可用的字体文件。过去这一步需要 RD 协助或使用付费软件，此工具让设计师在浏览器中自行完成。

纯前端运行，不需要服务器、不需要安装，直接用浏览器打开 `SVG2TTF.html` 即可使用。

**输入：** 一份 SVG 文件（Illustrator 输出）+ 一组 Unicode 对应清单
**输出：** 一个可直接安装使用的 `.ttf` 字体文件

主要能力：

- 自动解析 SVG 中的 `path`、`g`、`polygon`、`rect`、`circle`、`ellipse`，每个独立对象或群组视为一个字符
- 依「从左到右、从上到下」的坐标顺序自动排序字符并对应 Unicode
- 支持用水平基准线（`<line>`）保留每一行字符的垂直位置
- 两种 Unicode 对应输入模式：纯文本（如 `ABCDEFGabcdefg`）或逐行 `uniXXXX` 码位
- 实时字符检测预览，显示 bounding box、字符编号与对应结果
- 可选 EM 1000 或 EM 2048 两种字身框大小

## 使用方式

### 前置准备（Illustrator）

1. 将 JPG 或 PNG 图片置入 Illustrator，使用「图像描摹」（Image Trace）忽略底色后转为矢量图
2. 展开（Expand）并解散群组，取得独立的矢量对象
3. 复合字符（如 i、j、%）请将多个部件重新群组
4. 确认字符排列顺序：工具依「从左到右、从上到下」的位置对应 Unicode
5. 若需保留字符的垂直位置，在画布上每一行画一条水平线段作为基准线，工具会自动为每个字符对应最近的基准线
6. 完成后存为 SVG（使用默认设置即可）

### 在工具中操作

1. 用浏览器打开 `SVG2TTF.html`
2. 上传 SVG 文件，工具会依坐标顺序解析出所有字符
3. 设置 Unicode 对应：上传 `.txt` 文件或直接粘贴文字／uni 码位清单，**数量须与检测到的字符数一致**
4. 选择 EM 大小：1000 或 2048
5. 输入文件名（默认为 `SampleFont.ttf`）
6. 确认右侧「字符检测预览」中每个字符的 bounding box 与 Unicode 对应无误
7. 点击「下载 TTF」

> ⚠️ 制作下一套字体前，请刷新页面或点击「清除全部」，避免上一批数据残留。

## 注意事项

- SVG 文件超过 10MB 时解析会较久，但仍可继续操作
- `<line>` 元素只作为基准线标记，不会被当成字符
- `polyline`（开放路径）不会被视为字符，需使用 `polygon` 或封闭的 `path`
- 纯文本模式的输入不可含空格或换行，否则会造成字符数量误判
- 若 Unicode 数量与检测到的字符数不一致，画面会提示差异数量，请回 Illustrator 检查是否有遗漏或多余的对象

## 技术说明

- 纯前端 Vanilla JS，无外部依赖，所有逻辑（SVG 解析、路径转换、TTF 封装）皆内置于单一 HTML 文件中
- 内部以自制的 `TtfBuilder` 直接组装 TTF 二进制结构（sfnt 表格：`glyf`、`loca`、`cmap`、`hmtx`、`OS/2` 等）
- 圆形、椭圆与圆角矩形以三次贝塞尔曲线近似后，转换为 TrueType 二次贝塞尔曲线轮廓
- capsHeight / xHeight 会依检测到的大写与小写字符自动估算，找不到时依 EM 大小使用默认值
